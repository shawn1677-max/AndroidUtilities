# Privacy Policy — Utility Box

**Last updated: 26 August 2026**

## The short version

Utility Box collects nothing, stores nothing about you, and sends nothing
anywhere. The app does not request the `INTERNET` permission, so it is
technically incapable of transmitting data off your device.

## Data we collect

None. There are no accounts, no analytics, no crash reporting services, no
advertising identifiers and no third-party SDKs that gather data.

## Data the app reads on your device

Some tools read information from the device to show it back to you. This data
is displayed on screen and then discarded. It is never written to a server,
never shared with third parties, and never leaves the app.

| Tool | What it reads | What happens to it |
| --- | --- | --- |
| Device Info, Battery, Storage | Hardware, OS and battery statistics from the Android platform | Displayed only |
| Network Info | Connection type and the device's own IP addresses | Displayed only |
| Sensor Explorer, Compass, Bubble Level | Live sensor readings | Displayed only |
| App Inventory | Names, versions and sizes of apps you can launch | Displayed only |
| Sound Meter | Microphone audio, converted to a loudness number in memory | Never recorded or saved |
| QR Scanner | Camera frames, decoded in memory | Never photographed or saved |

## Permissions

| Permission | Why | When it is asked for |
| --- | --- | --- |
| `CAMERA` | Read QR codes and barcodes in the QR Scanner | Only when you open the QR Scanner |
| `RECORD_AUDIO` | Measure ambient loudness in the Sound Meter | Only when you open the Sound Meter |
| `VIBRATE` | Trigger the haptic motor in the Vibration Test | Granted at install, no prompt |
| `ACCESS_NETWORK_STATE` | Report the current connection type in Network Info | Granted at install, no prompt |

Declining the camera or microphone permission disables only that one tool.
Every other tool continues to work.

## Data the app stores

The only thing the app saves is your Screen Ruler calibration setting, kept in
the app's own private preferences on the device. Uninstalling the app removes
it. Nothing else persists between sessions — generated passwords, scan results,
hashes and measurements exist only while the screen is open.

## Files the app creates

Sharing a QR code writes a single PNG into the app's private cache so another
app can receive it. It is overwritten each time you share and removed when
Android clears the cache or you uninstall the app.

## Children

The app contains no ads, no purchases and no user-generated content, and
collects no data from anyone, including children.

## Changes

If this policy ever changes, the updated version will be published here and the
date at the top will change.
